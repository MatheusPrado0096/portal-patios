# Portal de Pátios para GitHub Pages

## Publicar

1. Adicione os PDFs à pasta `docs`.
2. Abra `editor.html` no computador e cadastre os pátios e ABRs.
3. Baixe o novo `data.js` e substitua o arquivo existente.
4. Envie o conteúdo desta pasta para um repositório público no GitHub.
5. Em Settings > Pages, selecione Deploy from a branch, `main` e `/ (root)`.

## Atualizar

- PDF: envie ou substitua o arquivo dentro de `docs`.
- Catálogo e links: abra `editor.html`, carregue `data.js`, edite, baixe e substitua no GitHub.

## Limitações

O GitHub Pages é estático. Não há upload permanente pelo site, banco de dados ou senha administrativa no próprio portal. A conta GitHub protege as alterações. Os PDFs publicados ficam acessíveis para qualquer pessoa com o link.
